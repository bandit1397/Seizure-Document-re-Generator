# 처리 절차 및 필요 서류

## 1. 처리 순서

```
① 검찰 요구 형식 확인 (KICS 보완수사요구인지, 기록 보완 요청인지)
        ↓
② 오기 범위 확인: 품명 3건이 적힌 서류를 모두 찾기
   압수조서 · 압수목록 · 압수목록교부서 · 임의제출서 · 가환부영수증
   · 압수물 총목록 · 피의자신문조서 · 범죄사실(피해품·피해액)
        ↓
③ 동일성 확인: 압수 당시 사진, 상품코드(품번), 현품 개봉 또는 피해업체 확인
        ↓
④ 피해액 변동 여부 확인 (정정 후 단가 합계)
        ↓
⑤ 정정 압수목록 교부 (임의제출자에게, 현재 날짜로, 수령 서명)
        ↓
⑥ 수사보고 + 대조표 + 사진대지 + 확인서류 작성
        ↓
⑦ 보완수사 결과 통보서(또는 추송서)로 검찰에 송부
```

## 2. 필요 서류

| 구분 | 서류 | 작성일 | 비고 |
|---|---|---|---|
| **필수** | 수사보고(압수물 품명 오기 확인 및 정정) | 현재 | 오기 원인, 3건 정정 내용, 동일성 확인 근거, 피해액 영향, 조치 사항 |
| **필수** | 압수물 품명 정정 전·후 대조표 | 현재 | 연번 × 해당 서류별로 정리 |
| **필수** | 사진대지(압수물 확인) | 현재 | 포장 앞·뒷면, 상품코드, (보관 중이면) 개봉 후 내용물 |
| **필수** | 보완수사 결과 통보서 **또는** 추송서 | 현재 | 검찰 요구 형식에 맞춤 |
| **권장** | 압수목록 교부서(품명 정정) | 실제 교부일 | 임의제출자에게 교부하고 수령 서명. 최초 압수일은 따로 적음 |
| **권장** | 임의제출자 확인서 | 실제 확인일 | 제출한 물건이 같다는 것과 정정 품명에 이의 없음을 확인 |
| **권장** | 피해품 확인서(피해업체) | 실제 확인일 | 상품코드·상품명·판매가를 확인. 가환부한 경우에는 사실상 필수 |
| 해당 시 | 범죄사실 정정 내용(수사보고에 포함) | 현재 | 피해액이 바뀌는 경우에만 |

## 3. 하지 말아야 할 것

- 송치된 **원본 서류에 두 줄을 긋고 정정하거나 날인하는 것**
  (작성 당시의 정정 방법을 송치 후에 쓰는 것은 안 됨)
- 압수조서·압수목록·교부서·임의제출서를 **최초 압수일 날짜로 새로 작성해 바꿔 넣는 것**
- 피의자에게 **소유권포기서를 다시 받는 것** (피해품이라 효력이 없음)
- 실제로 하지 않은 확인이나 교부를 **완료형으로 적는 것**

## 4. 검사가 '압수조서·압수목록 자체를 다시 작성하라'고 하는 경우

이 경우에도 원본은 그대로 두고 **제목에 "(품명 정정)"을 붙여 현재 날짜로 새로 작성**합니다.
본문 첫 줄에 "본 서류는 20○○. ○. ○.자 압수조서(압수목록)의 품명 오기를 정정하기 위하여 작성한 것으로, 원본을 대체하지 않음"이라고 적습니다.

## 5. 압수물 상태에 따른 차이

| 상태 | 동일성 확인 방법 | 추가 사항 |
|---|---|---|
| 경찰서 보관 중 | 참여인을 입회시키고 현품 개봉 후 촬영 | 개봉 사실을 수사보고에 적음 |
| 검찰 송부(검찰 보관) | 검찰 압수물 담당자와 협의해 현품 확인 | 확인 일시와 장소를 적음 |
| 피해업체에 가환부 | 압수 당시 사진, 상품코드, 점장 확인, CCTV | 가환부 영수증의 품명도 대조표에 넣음 |
