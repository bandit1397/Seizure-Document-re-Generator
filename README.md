# Seizure Document re-Generator

송치 후 **압수물 품명 오기**를 지적받아 보완을 요구받았을 때 필요한 서류를 정리하고 생성하는 도구입니다.
(예: 다이소 절도 현행범 체포, 미개봉 상품을 겉모양만 보고 적어 '팔토시'를 '장갑'으로 기재한 경우)

## 핵심 원칙

1. **송치된 원본은 고치지 않는다.** 압수조서, 압수목록, 압수목록 교부서, 임의제출서에 줄을 긋거나 최초 압수일 날짜로 다시 만들지 않습니다.
2. **현재 날짜로 정정 서류를 새로 만든다.** 수사보고와 정정 전·후 대조표를 작성합니다.
3. **같은 물건임을 증명한다.** 압수 당시 사진, 포장 상품코드, 현품 개봉 또는 피해업체 확인을 활용합니다.
4. **피해품과 피해액이 함께 맞는지 확인한다.** 범죄사실, 피의자신문조서, 가환부 영수증도 확인합니다.
5. **정정 압수목록을 임의제출자에게 다시 교부한다.** (권장)
6. 검찰 요구 형식에 맞춰 **보완수사 결과 통보서 또는 추송서**로 보냅니다.

## 한글(HWPX) 서류 — 압수물이 경찰서로 반환된 경우

`hwp/` 폴더의 `.hwpx` 파일은 한글 2014 이상에서 바로 열립니다. `.hwp`가 필요하면 한글에서 **다른 이름으로 저장 → HWP 문서**를 선택하세요.

| 파일 | 내용 |
|---|---|
| 00_전체묶음(01-08).hwpx | 01~08을 한 파일로 묶은 것 |
| 01_수사보고(압수물품명정정).hwpx | 반환 수령, 현품 확인, 정정 내용, 조치 사항 |
| 02_압수물품명_정정전후_대조표.hwpx | 3건 정정 전·후 |
| 03_사진대지.hwpx | 포장 앞·뒷면, 개봉·재봉인 사진 칸 |
| 04_압수목록교부서(품명정정).hwpx | 임의제출자에게 교부하고 수령 서명 |
| 05_임의제출자_확인서.hwpx | 제출 물건과 같다는 확인 |
| 06_피해품_확인서.hwpx | 피해업체 상품코드·판매가 확인 |
| 07_압수물총목록(품명정정).hwpx | 압수물을 다시 송부할 때 첨부 |
| 08_보완수사결과_통보서.hwpx | 보완수사요구를 받은 경우 |
| 09_추송서(08대신_택1).hwpx | 기록 보완 요청을 받은 경우 (08 대신 사용) |

사건 정보를 바꿔 다시 만들려면 `hwp/build_hwpx.py` 위쪽의 `CASE`, `ITEMS`를 고친 뒤 실행합니다.

```
pip install python-hwpx==6.8.0
python hwp/build_hwpx.py
```

## 생성기 사용법

1. `generator/index.html`을 브라우저(크롬, 엣지)로 엽니다. 설치나 인터넷 연결은 필요 없습니다.
2. 왼쪽에 사건 정보와 오기 물품(연번, 정정 전, 정정 후, 수량, 상품코드, 단가)을 입력합니다.
3. **실제로 마친 조치만 체크합니다.** 체크하지 않은 항목은 수사보고에 '~할 예정'으로 적힙니다.
4. 오른쪽 미리보기에서 문구를 직접 고친 뒤 **인쇄 / PDF 저장**을 누릅니다. 빨간 안내 상자는 인쇄되지 않습니다.

> 생성된 서류는 실무용 초안입니다. 소속 기관의 서식과 KICS 절차, 담당 검사의 요구 내용에 맞게 확인한 뒤 사용하세요.
